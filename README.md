# PowerWidget Android ⚡️

Виджет мониторинга отключений электроэнергии (ЦЕК) и реального датчика СвітлоБот для экрана Android.

## Возможности
- 🟢 / 🔴 Крупный статус света прямо на рабочем столе без входа в Telegram.
- 📡 Отображение реального статуса по датчику (очередь 2.1, ул. Грушевского, 70).
- ⏳ Обратный отсчёт до следующего отключения или включения по официальному графику ЦЕК.
- 🔄 Мгновенное обновление по нажатию на кнопку.
- 🚀 Автоматическая проверка и установка обновлений через GitHub Releases.

## Установка
1. Скачайте файл `PowerWidget.apk` из раздела **Releases**.
2. Установите на телефон Android.
3. Добавьте виджет на рабочий стол долгим нажатием на экран -> «Виджеты» -> «Монитор Света».
